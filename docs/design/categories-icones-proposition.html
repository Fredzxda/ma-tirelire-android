Un repère visuel pour chaque catégorie

Placement validé · 64 pictogrammes monochromes. Les icônes accompagnent les catégories, sans remplacer leurs noms ni ajouter une nouvelle ligne aux cartes.

Le catalogue

Dessins géométriques originaux, grille 24 × 24, trait de 1,7. Le fichier JSON voisin contient les 64 identifiants stables et leurs tracés SVG.

Aperçu dans les opérations

Cliquer sur une icône la sélectionne pour l’opération simple. En mode ventilation, cliquer pour ajouter ou retirer une catégorie de l’aperçu.

Carte d’une série

Recommandation : icônes à gauche du statut, date à droite. Sans statut de série, les icônes occupent la même place. Une ventilation montre au plus trois pictogrammes distincts, puis « +N ».

Les noms de catégories restent sous la description. Les virements internes gardent une seule mention « Virement interne lié », avec la typographie des autres métadonnées.

Ceci est une maquette locale : aucune modification de votre coffre, aucune affectation enregistrée, aucun accès réseau.
